# support

Where to ask, for every repository of the cyberia-to organization.

| you want | go to |
| --- | --- |
| to find the right repository | the [registry](README.md#registry) |
| to understand the stack | [soft3.org](https://soft3.org) and [soft3/docs](https://github.com/cyberia-to/soft3/tree/main/docs) |
| to understand the protocol | [cyber.page](https://cyber.page) |
| to run the robot | [cyb.ai](https://cyb.ai) and [cyb](https://github.com/cyberia-to/cyb) |
| to become a citizen | [cyberia.to](https://cyberia.to) |
| to report a bug | an issue on the repository the registry names |
| to report a vulnerability | [SECURITY.md](SECURITY.md) |
| to follow what changed | [cyberia.blog](https://cyberia.blog) |

An issue that arrives at the wrong repository is transferred, not closed. An
issue with a reproduction (command, revision, output) is answered first.
